# Simbia Captions — возможности

[English](FEATURES.md)

Нативный редактор macOS для вертикальной UGC-рекламы (9:16): шоты, субтитры, заголовки, моушен-графика, цвет, звук и экспорт в одном окне. Файл проекта Claude может править одновременно с вами. Интерфейс на **английском, русском и французском** (меню *Язык*).

## Стартовый экран


- **Последние проекты**: группы проектов из папки последнего открытого проекта, свежая группа первой. В каждой строке: диапазон номеров («VD 12–15»), категория, число проектов в каждом статусе и по плитке на каждое видео (кадр первого шота в кольце цвета статуса). Клик по плитке открывает видео.
- **Все проекты** открывает браузер проектов.
- **Загрузить видео** открывает видео (или перетащите файл в любое место окна). Речь распознаёт сам Mac, на устройстве; **Язык речи: <язык>** задаёт язык.
- **Загрузить готовый SRT** после выбора видео, если субтитры уже есть.
- Во время работы: зацикленный логотип, прогресс в %, строка статуса и свечение по краю окна.

## Браузер проектов


- Сетка на всё окно: все проекты `.simbia` в папке, по группам (подряд идущие номера VD одной категории, до 4), сначала новые.
- Фильтры **Все / Новый / На проверке / Готово** с количеством; **Поиск…** по названию; Esc закрывает.
- Плитка: кадр 9:16, значок статуса, «ОТКРЫТ» на открытом проекте, номер VD, длина, открытые задачи («осталось: N»).
- Клик выделяет проект и показывает панель деталей; двойной клик открывает. Правый клик: сменить статус, Открыть, Показать в Finder.
- Панель деталей: постер, название, длина · шоты · субтитры, ревизия и кто сохранил, **кнопки статуса**, список **Предстоит** (отметить, добавить через «Новая задача…», правый клик удаляет) и **журнал правок** (последние 30 записей, вы синим, Claude оранжевым).
- Смена статуса и задач у закрытого проекта записывается в его файл новой ревизией, с записью в журнале.

## Бриф и задачи


Нажмите на название проекта в шапке.

- Переключатель статуса (Новый / Проверка / Готово), **Карточка** (открывает ссылку на карточку брифа), **Все проекты**, закрыть (Esc).
- **Референсы**: ссылки и файлы, у каждого типа свой значок; веб-ссылки открываются в браузере, файлы в своих программах.
- **Над чем работаем**, **Хук этого ролика**, **Что от нас требуется**.
- **Сцены по порядку**: кто, суть, точный текст реплики и жёлтая строка **В монтаже:** там, где монтаж отличается от брифа.
- **Проверить** (жёлтым): задачи, отмеченные на проверку, с кнопкой **Проверено**, число замечаний проверки перед экспортом с кнопкой **Открыть**, отмеченные шоты и звуки.
- **Осталось сделать** и **Сделано**; задачи добавляются через «Новая задача…»; правый клик удаляет.
- **Последние правки**: 12 последних записей журнала, ваши и Claude.

## Окно редактора

- Одно окно, один проект. Другой открытый проект заменяет текущий (меню **Проекты**: *Открыть проект…* ⇧⌘O, *В этой папке*, *Недавние*, *Показать проект в Finder*).
- Шапка: кнопка сетки проектов, название проекта (открывает бриф) со статусом, размер кадра · длина · шоты · субтитры · абзацы · заголовки, **плашка синхронизации** («Claude · синхронизировано» или «Обновлено Claude · ⌘Z» после внешней правки; «Не связано с Claude» → *Сохранить как проект…*), Отменить, Повторить, **SRT**, **Проверка**, **Экспорт**.
- Плеер: тот же рендерер, что и в экспорте (субтитры, заголовки и графика рисуются вживую с частотой кадров видео). Транспорт: время, предыдущий субтитр, воспроизведение/пауза, следующий субтитр.
- **Как это будет выглядеть**: TikTok / Instagram Reels / Без рамки. Полупрозрачный макет интерфейса приложения, небезопасные полосы затенены.
- **Тяните по картинке**, чтобы двигать субтитры, заголовки, карточки отзывов, сцены из кита, видео поверх и эмодзи. Пока тянете, видны безопасная зона и центральные линии; элементы прилипают к центру, к краям безопасной зоны и к своему исходному месту (⌘ выключает магнит); элемент за пределами безопасной зоны получает оранжевую обводку. Двойной клик возвращает элемент на место.
- **Выровнять все заголовки по этому** (правый клик по заголовку, ⇧⌘A): все остальные заголовки встают на высоту этого, одним шагом отмены.
- Превью краёв: при подрезке, сдвиге содержимого или переносе склейки поверх картинки видны кадры, которые окажутся на краях («первый кадр · 33.75 с»), как в Final Cut.
- Уведомления вверху картинки; во время долгих операций поверх показывается прогресс. История отмены: 120 шагов по всем действиям.

## Таймлайн


- Дорожки сверху вниз: линейка, **Такты**, **Заголовки**, **Графика**, фильтр **Общий**, **Фильтры**, **Наложение**, **Ключи** кадрирования, **Шоты**, привязки голоса, **Голос**, **Субтитры**, **Музыка**.
- Перемотка: тяните по линейке или по любой пустой дорожке. Масштаб: щипок, ⌥-прокрутка или переключатель масштаба (*Отдалить*, *Приблизить*, *Весь ролик*); прокрутка двумя пальцами сдвигает вид.
- **Привязка**: склейки, заголовки, субтитры и края шотов прилипают к долям музыки. Метка темпа «N BPM»; на дорожке «Такты» пронумерованные такты и отметки долей.
- **Создать субтитры**: Mac делает субтитры для каждого клипа голоса (или для всего видео), каждый клип отдельным абзацем.
- **Вырезать паузы** открывает инструмент пауз.
- Названия дорожек открывают панель настроек этой дорожки под ней (Заголовки, Графика, Фильтры, Переходы, Субтитры: *Абзац / Весь текст / Стили*). Название *Музыка* открывает аудиобиблиотеку.
- При наведении на пустой участок тонкой дорожки появляются: **+ Заголовок**, **+ Графика** (выбрать отзыв), **+ Видео поверх**, **+ Кадрирование с ключами**, **+ Субтитры по голосу** (только на этом участке), **+ Общий фильтр**, **+ Фильтр на длину клипа**.

## Шоты

- В ячейках миниатюра и название; у отмеченных шотов красная точка, у затемнённых под графику синяя обводка.
- Клик выделяет шот и переносит курсор воспроизведения; **двойной клик** заменяет видео (видео проекта или библиотека футажей); **правый клик** открывает окно шота.
- **Перетаскивание меняет порядок** → *С голосом и субтитрами* (вместе с шотом едут его голос, звуки, субтитры, заголовки, сцены и фильтры) или *Только видео*.
- **Сдвиг содержимого** (золотая полоса сверху): показать другой момент клипа; шот остаётся на месте и той же длины, его собственный звук сдвигается вместе с картинкой.
- **Перенос склейки** (верхняя золотая ручка): двигает склейку между двумя шотами. **Подрезка со сдвигом** (нижняя белая ручка): меняется только этот шот, всё после сдвигается; при укорачивании все слова сохраняются.
- Ручка склейки: **+** на склейках выделенного шота → *Видео* (вставить до 5 с, всё после сдвигается) или *Переход*.
- **S** разрезает по курсору воспроизведения (с привязкой к доле; вторая половина получает обратное движение камеры).
- **Окно шота**:
  - *Клип*: начало в клипе (±0.5 с), *Заменить клип…*, *Разрезать · S*, *Показать в Finder*.
  - *Скорость*: ×0.25…×4 (логарифмический ползунок, пресеты ×1/×1.5/×2/×3, точное значение). Шот сохраняет место и длину, его звук следует за ним с сохранением высоты тона; у замедленных шотов **промежуточные кадры по оптическому потоку** (без повторов кадров).
  - *Камера*: Наезд / Отъезд / Без, *Отразить по горизонтали*, *Затемнить под графику*, *Кадрировать…*, *Закрыть текст…*, *Без кадрирования*, *Убрать закраску*.
  - *Цвет* (см. [Цвет](#цвет)).
  - *Что не так — увидит Claude*: Лицо не похоже, Одежда · причёска, Артефакты · морфинг, Не тот план · ракурс, Взгляд · в камеру, Губы не в синхрон, Голос · реплика, Фон · предметы двигаются, Непонятно · нет логики, Мыло · качество, Переделать целиком, плюс заметка. Сохраняется в проекте для Claude.
  - *Библиотека*: *Видео проекта…*, *Вся библиотека…* и три автоматических варианта из индекса футажей под текст, который звучит на этом шоте.
  - *Удалить шот · ⌫* (со сдвигом: его голос и субтитры уходят вместе с ним) или *Удалить картинку* (соседние шоты растягиваются на его место, голос и длина остаются).

## Видео поверх, хромакей и трансформация

- На дорожке **Наложение** лежат видео поверх картинки: тяните, чтобы сдвинуть (прилипает к склейкам и долям), тяните края, чтобы подрезать, двойной клик заменяет, ⌫ удаляет, файл из Finder можно бросить прямо на дорожку. **S** разрезает.
- Без настроек слой закрывает картинку, пока играет; с ключом или трансформацией он накладывается поверх, как Keyer + Transform на присоединённом клипе в Final Cut.
- **Вырезать фон** (зелёный / синий экран): образец цвета (авто или *Пипетка*), *Сила*, *Зелень на персонаже*, *Края*, *Мягкость*, **Показать маску** (только в окне просмотра).
- Размер 10–100 %, поворот ±180° (ловит ровное положение), сдвиг X/Y в px, *Во весь кадр*; или тяните видео и его угловую ручку прямо на картинке.

## Кадрирование, ключи кадрирования и закраска текста


- **Кадрировать** (на картинке на паузе): весь исходный кадр, используемая часть выделена белой рамкой; тяните, чтобы сдвинуть, тяните угол или сведите пальцы, чтобы изменить размер (до 400 %), ползунок масштаба, поворот на 90° влево/вправо и точный поворот ±45°, *Без кадрирования*, *Отмена* (Esc), *Готово* (Return).
- **Ключ в этой точке**: сохраняет рамку как ключ кадрирования; между ключами кадр плавно движется (наезд или панорама). Ключи лежат на дорожке «Ключи»: тяните их по времени, правый клик удаляет, дугу между двумя ключами тяните вверх или вниз, чтобы движение плавно разгонялось или тормозило.
- **Закрыть текст**: закрасить вшитые субтитры или логотипы. *Найти текст* (Vision находит текст на шоте и добавляет зоны), *+ Зона*, двигайте зоны и меняйте их размер, *Заливка* (от краёв зоны, с подобранным зерном) или *Размытие*, мягкость края (*Край*).

## Цвет


- **Цвет шота** (окно шота): вкл/выкл (выкл = шот как снят), *Яркость*, *Контраст*, *Насыщенность*, *Теплота*, *Оттенок*, *Подгонка к сцене*. Изменения видны сразу, без пересборки превью. Двойной клик по значению сбрасывает его.
- **Подогнать цвет**: *Как предыдущий*, *Как следующий*, *Под эталон*, *Сделать эталоном*.
- **Помада** (шот или фильтр): губы находятся на каждом кадре по точкам лица; *Губы · помада* (сила), *Мягкость края губ*, *Цвет помады*, *Защита зубов*, *Половина рта* (весь рот / левая / правая, для сравнения «до/после» на двух половинах лица).
- **Вкладка «Фильтры»**: **Общий фильтр** на весь ролик (*Контраст · кривая*, *Насыщенность*, *Теплота*, *Оттенок*, *Бирюзовые тени · тёплые света*, *Мягкий чёрный*, *Виньетка*, *Зерно*), **Размытие движения · затвор** 0–360° (попиксельное размытие движения, 180° = как в кино) и **Размытие на склейках** (смаз в следующий шот, как при резком рывке камеры).
- **Клипы-фильтры** на дорожке «Фильтры» на отрезке ролика: название, яркость, контраст, насыщенность, теплота, оттенок, помада. *Сравнить с исходником* переключает до/после.

## Переходы


- На любой склейке: **Растворение, Через чёрное, Вспышка, Рывок, Зум внутрь, Зум наружу, Через размытие, Сдвиг**.
- *Длительность* 0.1–2 с; направление для «Рывка» и «Сдвига»; используется материал за склейкой (или удерживается крайний кадр). *Удалить переход · ⌫*.

## Субтитры


- **Распознавание** на Mac, на устройстве: язык задаётся на стартовом экране; недостающие языковые файлы скачиваются сами. Слова из **словаря** передаются как подсказки, похожие ошибки исправляются (бренд в первую очередь).
- После распознавания субтитры прилипают к реальному началу и концу голоса, а короткие промежутки между ними закрываются.
- Слова собираются в субтитры по семейству стиля: одна строка (до 3 слов, разрыв на знаках препинания) или две строки (одно предложение). Абзац начинается после предложения или паузы 0.7 с, пока вы не расставите абзацы вручную.
- **Таймлайн**: клик, ⇧-клик для диапазона, ⌘-клик для добавления; тяните субтитр (соседи уступают место и возвращаются), подрезайте его края, тяните разделители слов внутри него (по кадрам).
- Меню по правому клику: *Объединить выделенные · M*, *Сделать одним абзацем*, *Разделить перед словом ▸*, *Объединить с предыдущим / со следующим*, *Пересчитать по словам*, *Пересчитать все субтитры по словам*, *Начать абзац с этого субтитра · ↩*, *Выделить абзац*, *Удалить · ⌫*.
- Вкладка **Весь текст**: расшифровка пронумерованными абзацами; субтитр под курсором воспроизведения обведён; слова под указателем увеличиваются. Клик по слову открывает **инструменты слова**: правка слова, *Выделить* (акцент), *Разрыв* (с этого слова начинается новый субтитр), *Абзац*, *Удалить*, *Звучит* (начало/конец ±1 кадр), Начало/Конец субтитра, *Объединить с предыдущим / со следующим*, *Растянуть до следующего*, *Удалить субтитр*.
- Вкладка **Абзац**: выбранные субтитры на мини-линейке с волной голоса; тяните слова, чтобы сдвинуть их начало, тяните ячейку, чтобы сдвинуть субтитр, поля Начало/Конец.
- При перепечатке тайминг неизменённых слов сохраняется; слово, набранное как несколько, делит своё время между ними; поля времени принимают 1:02.5, 62.5 и 62,5.
- **Пересчитать по словам**: слова возвращаются туда, где сейчас звучит их голос (по сохранённым якорям голоса или новым распознаванием).
- **Создать субтитры по звуку** на клипе голоса; **+ Субтитры по голосу** на участке.

## Стили субтитров


| Стиль | Как выглядит |
|---|---|
| s1 Gold Script | Montserrat 800, белый; акценты Playfair Display Italic с бегущим золотым градиентом |
| s2 Highlighter | заглавные Archivo Black, белые с тёмной обводкой; акценты закрашиваются розовым маркером |
| s3 Editorial | DM Sans 700, кремовый, поднимается из своей плашки; акценты DM Serif Display Italic, розовые |
| s4 Handwritten Note | Poppins 700, въезжает; акценты Caveat, красные, с рукописным подчёркиванием |
| s5 Clean Box | Inter Tight 800 на белых скруглённых карточках; акценты золотые на тёмной карточке |
| s6–s10 | те же пять стилей, целое предложение на двух ровных строках |
| s11 Обычные / s12 Обычные · 2 | Montserrat 800, белый, тонкая обводка, мягкая тень; одна или две строки |
| s13 Фильм / s14 Фильм жирный | субтитры Inter 48 px с разбивкой строк как у Netflix |

- Для всего видео: **ВСЕ ЗАГЛАВНЫЕ**, **Курсив**, **Акцентные слова** вкл/выкл, **Между строк**, а для стилей «Обычные» **Появление**: Pop, По словам, Снизу, Плавно, Караоке.
- Переключение одна строка ↔ две строки перегруппирует слова внутри абзацев; тайминг и акценты сохраняются.
- Нативный рендерер повторяет веб-эталон правило в правило (`Reference/overlay_ref.html`): те же шрифты, раскладка, ключевые кадры и порядок теней.
- **Классика** (прежние стили программы на libass): пресеты PLATE, HORMOZI, BEAST, CLEAN, NEON, POSTER, RETRO, MONO, HIGHLIGHT, SOFT; 10 появлений и 10 угасаний с живым превью; шрифт, размер, межбуквенный интервал, выравнивание, разбивка (1 слово / 2 слова / 2 строки), цвета текста, фона, обводки, тени и свечения, акцентный шрифт, наклон и цвет.

## Графика, сцены из кита и отзывы


- Кнопки **Коллаж отзывов**, **Слайдер отзывов**, **Комментарии** добавляют эту графику у курсора воспроизведения.
- **Сцены из кита** (папки PNG-кадров из `RENDER_KIT/motion/frames`): клик ставит сцену у курсора воспроизведения; на дорожке тяните, чтобы сдвинуть, тяните правый край, чтобы изменить длину (сцена держит кадр, потом уходит); *Заменить на…* меняет сцену на родственную в том же месте и времени.
- **Стекло** под сценой: картинка под ней размыта, светлее и преломляется по краю, как матовое стекло.
- **Отзывы Trustpilot** из `_ASSETS/TRUSTPILOT/reviews.json`: клик добавляет карточку отзыва или меняет и добавляет отзывы на выделенной карточке, в коллаже или слайдере. *Свой отзыв* создаёт пустую карточку; *В библиотеку* добавляет её в reviews.json.

## Звук


- Дорожки **Голос** и **Музыка** с формой волны; на музыке видны провалы под голосом.
- Тяните клип, чтобы сдвинуть, тяните края, чтобы подрезать; **ручки фейда** в углах, тяните склон фейда, чтобы изогнуть его; **S** разрезает; ⌫ удаляет; аудиофайл из Finder можно бросить на дорожку «Музыка».
- Привязка под каждым клипом голоса: клип привязан к своему шоту (едет вместе с ним) или свободен.
- **Окно звука**: громкость −45…+12 дБ (*Как записано*, *Без звука*); для голоса *Создать субтитры по звуку*; для музыки **Сайдчейн** (*Приглушать, когда звучит голос*, насколько тише, время ухода и возврата); *Другой трек…*.
- **Обработка голоса · все голоса**: выравнивание до целевого LUFS, компрессия (мягко / средне / плотно, по образцу FabFilter Pro-C 2 «Pro Voice Over») и true-peak лимитер (как Pro-L 2).
- *Что не так — увидит Claude*: Глитч · щелчок, Слово обрезано, Не тот голос, Не в синхрон, Громкость, Лишняя пауза, Переозвучить, плюс заметка.
- Превью применяет громкость, фейды, кривые и приглушение к каждому сэмплу, поэтому звучит точно как экспорт; изменения громкости применяются прямо во время воспроизведения.

## Аудиобиблиотека


- Все треки из `_ASSETS/MUSIC` (с подпапками): название, папка, длина, форма волны, громкость (LUFS) и где трек уже стоит («свободен», «в VD 12, 17»); *Сначала свободные*.
- Клик включает прослушивание, двойной клик или **Поставить** заменяет трек: место, длина, фейды и приглушение остаются, громкость подгоняется, чтобы трек звучал так же громко, как прежний. Один шаг отмены.
- Музыки ещё нет: трек ложится на весь ролик на стандартной громкости и затухает в конце.
- Темп и такты определяются по самой музыке; по сетке долей работает «Привязка».

## Футаж: видео проекта и библиотека футажей


- **Видео проекта**: папка с видео проекта по подпапкам, сначала новые, при наведении видео играет, *Загрузить видео…*, *Подключить папку…*, поиск; *Поставить в шот*, *Наложить поверх*, *Вставить на склейку*. Для наших ИИ-генераций показывает ещё промпт и модель.
- **Библиотека футажей** (`_ASSETS/_index`): каждый годный момент по категориям — Наносит помаду, Тюбик в камеру, Губы крупно, Улыбка, Говорит в камеру, Сухие губы, Другие помады, Продукт отдельно, B-roll; фильтры Амбассадоры / AI / Сток и продукт; сортировка Лучшие / Сначала новые / Сначала старые; поиск. Открывается в категории, которая подходит к тексту над шотом.
- *Скрыть из библиотеки* (розовый наконечник / плохой кадр / не наш продукт) убирает момент навсегда. Моменты со вшитым текстом, с пометкой «avoid» и с розовым наконечником не попадают в галерею и в подсказки.

## Проверка перед экспортом


Кнопка **Проверка** (и **Экспорт**, который сначала запускает её) выводит список; в каждой строке есть **Исправить**, в каждой группе и для всего списка **Исправить все**:

- субтитры наложились; повторы распознавания; написание (по словарю); текст уменьшен, чтобы поместиться; субтитры не по голосу; мигание у склейки (1–3 кадра); мигание между субтитрами (промежуток меньше 0.3 с); не успеть прочитать (меньше 0.3 с или больше 25 букв/с); заголовки короче 2 с; склейка внутри шота (исходный клип перескакивает на другую картинку); нет файлов.
- Экспорт предлагает *Экспортировать как есть* или *Исправить и экспортировать*.

## Инструменты текста

- **Найти и заменить** (целые слова, тайминг слов сохраняется), **Словарь** (слова, которые всегда пишутся одинаково; их используют распознавание и проверка написания), **Вырезать паузы** (длиннее 0.25–1.5 с; кадр говорящего и голос склеиваются встык с фейдами по 20 мс, остальное сдвигается, музыка играет дальше).

## Экспорт

- **Экспорт** (⌘E): нативный движок рендерит ровно то, что показывает превью (H.264 High, 10 Мбит/с, BT.709), затем ffmpeg нормализует звук до **−14 LUFS**, true peak −1.5 dBTP, AAC 192k.
- Если какого-то файла нет, экспорт останавливается и показывает список файлов.
- **Сохранить SRT** (⌘S), **Импорт SRT** (⇧⌘I). Простое видео только с классическими субтитрами прожигается через ffmpeg/libass.

## Файл проекта и живая синхронизация с Claude

- Весь монтаж хранится в одном JSON-файле `.simbia` (шоты, слои, звук, наложения, субтитры, заголовки, фильтры, переходы, бриф, задачи, статус). Двойной клик открывает его в программе.
- **Живая двусторонняя синхронизация**: ваши правки сохраняются через 0.3 с после остановки; изменение на диске (от Claude) подгружается на месте одним шагом отмены, ⌘Z возвращает вашу версию. Программа никогда не перезаписывает файл, который изменили где-то ещё после её последнего чтения.
- Каждое сохранение повышает `revision` и записывает, кто сохранил (`app` / `claude`); общий **журнал правок** (`_journal.jsonl`) простыми словами описывает, что изменил каждый из вас.
- Расшифрованное видео без проекта становится проектом в Application Support, и работа продолжается в следующий раз.

## Командная строка: `bin/simbia`

Движок без окна, для Claude и скриптов. Каждая команда, которая сохраняет, повышает `revision` и ставит `savedBy: "claude"`.

| Команда | Что делает |
|---|---|
| `check <project>` | сводка и всё, что отрисуется неправильно; строки с `~` стоит исправить |
| `fix <project> [kind …]` | исправить все (или названные) виды замечаний и сохранить |
| `pauses <project> [s] [--apply]` | паузы в голосе; `--apply` вырезает их |
| `suggest <project> <shot #>` | моменты из библиотеки под текст над шотом (шоты с 0) |
| `cuts <video> [from to]` | жёсткие склейки внутри клипа |
| `tempo <audio or project>` | bpm и первая сильная доля |
| `covers <project> <shot #> [--apply]` | зоны вшитого текста (шоты с 1) |
| `words <media> [from to] [--locale] [--hint] [--json]` | распознавание речи на Mac, слово за словом |
| `frame <project> <t,…> <prefix> [--no-overlay]` | собранные кадры в PNG |
| `overlay <project> <t,…> <prefix> [--style sN] [--no-titles]` | только субтитры и заголовки, PNG с прозрачностью |
| `export <project> <out.mp4>` | готовое видео |

| `restyle <project> <sN>` | стиль субтитров для всего видео |
| `captions <проект> [--clip id] [--style sN] [--script файл] [--locale]` | субтитры из голосовых клипов, с сохранением и записью в журнал; `--script` — ровно эти слова, время по голосу (непрозвучавшие слова перечислены) |

## Сочетания клавиш

Одиночные клавиши работают по положению клавиши (в том числе в русской раскладке) и не срабатывают во время набора текста.

| Клавиша | Действие |
|---|---|
| Пробел | воспроизведение / пауза |
| ← / → | на один кадр |
| J / K / L | челнок назад / стоп / вперёд (1×, 2×, 4×) |
| S | разрезать по курсору воспроизведения (субтитр, шот или звуковой клип) |
| M | объединить субтитры |
| ↩ | начать или соединить абзац |
| ⌫ | удалить выделенное |
| Esc | закрыть экран на всё окно, свернуть панель настроек, снять выделение |
| ⌘A | выделить все субтитры |
| ⌘O / ⇧⌘O | открыть видео / открыть проект |
| ⌘S / ⇧⌘S | сохранить SRT / сохранить проект как |
| ⇧⌘I | импорт SRT |
| ⌘E | экспорт видео |
| ⌘Z / ⇧⌘Z | отменить / повторить |
| ⇧⌘A | выровнять все заголовки по выбранному |

## Языки

Интерфейс на **английском, русском и французском**: меню **Язык** → English / Русский / Français. При первом запуске используется язык системы; выбор запоминается. Язык распознавания речи задаётся отдельно (стартовый экран, *Язык речи: …*).

Журнал проекта ведётся на русском (это данные, общие с Claude, а не текст интерфейса).
